About the project

BMITADBLOCKER is a DNS filtering platform that blocks ads and trackers across every app on a device, not just inside the browser. It uses the NextDNS resolver and analytics API, proxied securely through Cloudflare Pages Functions, and exposes a clean, real-time dashboard for query statistics, blocked domain rankings, and per-client connection status.

The platform pairs two complementary layers: network-level DNS blocking for system-wide protection, and a Manifest V3 browser extension for in-page cosmetic filtering and first-party ad blocking that DNS alone cannot catch.
